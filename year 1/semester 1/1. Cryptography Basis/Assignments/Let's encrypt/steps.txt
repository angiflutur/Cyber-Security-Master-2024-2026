1. Generate and display the hash value (you can choose between MD5, SHA-1 or SHA-256)

-----STEPS---------------------------------
	For this exercise, I chose MD5. The implemented flow in Cryptool is as follows:

- used components:
	- File Input (secret_message.txt) -> loads the text file into CrypTool
	- MD5 -> computes the hash of the file content
	- String Encode (settings: Presentation Format = Hexadecimal) -> to convert the binary hash in hexadecimal format
	- Text Output -> displays the final hash value

- connections between components:
	- File Input (Stream Output) -> MD5 (Input Stream)
	- MD5 (Hashed Value - ICrypToolStream) -> String Encode (Stream input - ICrypToolStream)
	- String Encode (Text Output) -> Text Output (Input Data)

-----RESULT----------------------------------
	8C 06 F1 EE 73 29 2E BB D8 74 DA A0 F7 C5 6A C2


2. Choose a classic cipher (Playfair, Vigenere, XOR) and a password and encrypt the file

-----STEPS---------------------------------
	For this exercise, I chose the Playfair cipher. The implemented flow in CrypTool is as follows:

- used components:
	- File Input (secret_message.txt) -> loads the text file into CrypTool
	- String Encode (settings: Presentation format = Text) -> converts the file input from stream format to text format (since Playfair doesn't accept stream input)
	- Text Input (Password: "ANGI") -> contains the key of the Playfair cipher
	- Playfair Cipher (default settings) -> to encrypt the text input with the given key
	- Text Output -> shows the encrypted message

- connections between components:
	- File Input (Stream Output) -> String Encode (Stream Input - ICrypToolStream)
	- String Encode (Text Output) -> Playfair Cipher (Text Input)
	- Text Input ("ANGI") -> Playfair Cipher (Key phrase - Text Input)
	- Playfair Cipher (Text Output) -> Text Output (Input Data)

-----RESULT----------------------------------
	UFGTGTGQFDSDSOMXQGEMDTPONGEMONKCFKTUDMICPRUQSW

4. Choose a password and encrypt the text using AES in ECB mode

-----STEPS---------------------------------
	For this exercise I will use the password "angiangiangiangi", which is 16 bytes long, as required by AES in ECB mode.

- used components:
	- File Input -> loads the text file into CrypTool
	- Text Input (password "angiangiangiangi") -> contains the password to be used for encryption
	- String Decode (input format = text) -> to convert the password from text to bytes (because AES requires the key to be in byte format)
	- AES (Configured with the settings below) -> encrypts the text using the password as the key
		- Action = encrypt
		- keysize = 128
		- chaining mode = ECB
		- padding mode = zeros
	- String encode (settings: Presentation format = hexadecimal)-> converts the encrypted text into hexadecimal
	- Text output -> displays the encrypted message

- connections between components:
	- File Input (Stream Output) -> AES (input)
	- Text input -> String Decode 
	- String Decode -> AES (key)
	- AES (Output stream) -> String encode
	- String encode -> text output

-----RESULT----------------------------------

8. Choose any PRNG available in CrypTool and implement a scenario in which the text is encrypted using an OTP approach.
	For this exercise i used Random Number Generator with the settings:
		- Algorithm: Random.Random
		- Output length (bytes): 54 bytes (the same length as File Input)
		- seed: 17
-----STEPS---------------------------------

- used components:
	- File Input + string encode + string decode -> because XOR component takes bytes as input

	- string encode + text output -> contains the final encrypted message

- connections between components:
	- File input -> String encode -> String Decode
	- Random Number Generator -> XOR (XOR key input)
	- XOR -> String encode -> Text output.
